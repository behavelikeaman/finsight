# Step 10: landing

## 읽어야 할 파일

먼저 아래 파일들을 읽고 프로젝트의 아키텍처와 설계 의도를 파악하라:

- `/CLAUDE.md`
- `/docs/PRD.md` (사용자, 핵심 기능, 디자인 절)
- `/docs/ADR.md` (특히 ADR-001, ADR-004, ADR-006, ADR-009, ADR-012)
- `/src/app/` 전체 구조
- `/src/types/tier.ts` (요금제 숫자의 단일 출처)

## 작업

`src/app/(marketing)/`에 랜딩 페이지를 만든다. 전부 Server Component로 작성한다 — 인터랙션이 없다.

### 대상 독자

한국의 프리랜서·1인 사업자다. "AI로 소비 패턴을 분석해드립니다" 같은 일반론은 이 사람에게 아무 의미가 없다. 카피는 구체적인 상황에서 출발해야 한다: 세무 신고철에 카드 명세서를 열어 사업경비를 손으로 골라내는 그 작업.

### 섹션 구성

1. **히어로** — 한 문장 가치 제안 + CTA 두 개: "무료로 해보기"(`/try`), "로그인"(`/login`). 가입 없이 바로 써볼 수 있다는 점을 CTA에 드러내라 (ADR-012의 전제).
2. **작동 방식 3단계** — 카드사에서 CSV 내려받기 → 업로드 → 거래별 분류 결과 확인·수정. 수동 업로드가 필요하다는 사실을 숨기지 마라. 숨기면 `/try`에서 이탈한다.
3. **무엇을 하고 무엇을 안 하는가** — 이 섹션은 반드시 넣는다.
   - 한다: 거래별 사업경비/개인지출 분류, 계정과목 매핑, 확신도 표시, 수정 학습
   - 안 한다: **세무 조언·절세 판단을 하지 않는다** (ADR-006). 이걸 약점이 아니라 신뢰 신호로 쓴다 — "판단은 세무 대리인의 몫이고, 우리는 그 앞 단계의 노동을 없앤다".
4. **데이터 취급** — ADR-004, ADR-005를 사용자 언어로 옮긴다. 카드번호·성명은 전송 전 제거, 분석은 Anthropic(미국) API 사용, 원본 파일은 30일 후 삭제. **국외 이전 사실을 명시한다.** 이건 법적 요구이자 신뢰 자산이다.
5. **요금제** — 무료 / 유료 두 칸. 숫자는 `TIER_LIMITS`에서 가져와 렌더링하라. 하드코딩하면 나중에 한도를 바꿀 때 랜딩과 실제 동작이 어긋난다. 결제는 아직 붙지 않았으므로 유료 CTA는 "준비 중"으로 비활성 처리한다.

### 카피 톤

과장하지 마라. "AI가 완벽하게"류의 문구는 ADR-007(확신도 기반 검토 유도)과 정면으로 모순된다. 제품이 틀릴 수 있고 사용자가 검토한다는 전제를 카피가 부정하면 안 된다.

### 디자인

PRD 디자인 절을 따른다: 라이트 모드, 무채색 + 포인트 컬러 1가지, 고밀도보다 가독성. 랜딩은 표 중심이 아니므로 여백을 넉넉히 쓴다.

Tailwind만 쓴다. UI 라이브러리를 추가하지 마라.

`src/components/marketing/`에 섹션 컴포넌트를 분리한다. 한 파일에 전부 넣지 마라.

### 메타데이터

`src/app/(marketing)/layout.tsx` 또는 page에 `metadata`를 정의한다. title, description, `og:` 태그. 한국어 `lang="ko"`가 루트 레이아웃에 설정되어 있는지 확인하고, 아니면 고쳐라.

### 테스트

렌더링 스모크 테스트 하나. 요금제 숫자가 `TIER_LIMITS`와 일치하는지 확인하는 테스트를 포함하라 — 하드코딩 회귀를 잡는다.

## Acceptance Criteria

```bash
npm run build   # 컴파일 에러 없음
npm test        # 신규 테스트 포함 전부 통과
npm run lint    # 에러 없음
```

## 검증 절차

1. 위 AC 커맨드를 실행한다.
2. 아키텍처 체크리스트를 확인한다:
   - 컴포넌트가 `src/components/marketing/`에 분리되어 있는가?
   - 전부 Server Component인가? (`"use client"`가 없어야 한다)
   - 요금제 숫자가 `TIER_LIMITS`에서 오는가?
   - 세무조언 미제공과 국외 이전이 명시되어 있는가?
3. 결과에 따라 `phases/0-mvp/index.json`의 step 10을 업데이트한다:
   - 성공 → `"status": "completed"`, `"summary": "산출물 한 줄 요약"`
   - 수정 3회 시도 후에도 실패 → `"status": "error"`, `"error_message": "구체적 에러 내용"`
   - 사용자 개입 필요 → `"status": "blocked"`, `"blocked_reason": "구체적 사유"` 후 즉시 중단

## 금지사항

- 수동 CSV 업로드가 필요하다는 사실을 감추지 마라. 이유: `/try`에서 알게 되면 배신감으로 이탈한다.
- 세무 조언을 암시하는 카피를 쓰지 마라 ("절세 도와드립니다", "경비 처리 가능 여부 판단"). 이유: ADR-006 위반이며 법적 리스크다.
- 국외 이전 사실을 생략하지 마라. 이유: 개인정보보호법상 고지 의무이자 ADR-004의 전제다.
- 요금제 숫자를 하드코딩하지 마라. `TIER_LIMITS`를 렌더링한다.
- UI 컴포넌트 라이브러리나 애니메이션 라이브러리를 추가하지 마라.
- `"use client"`를 쓰지 마라. 랜딩에 클라이언트 상태가 필요하지 않다.
- 결제 흐름을 만들지 마라. 유료 CTA는 비활성 상태로 둔다.
- 기존 테스트를 깨뜨리지 마라
