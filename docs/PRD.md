# PRD: FinSight

## 목표
프리랜서·1인 사업자가 카드 명세서를 올리면 AI가 거래별로 사업경비와 개인지출을 갈라주어, 세무 신고 전 경비 정리에 드는 수작업을 없앤다.

## 사용자
한국의 프리랜서·1인 사업자. 카드 한두 장을 사업과 개인 용도로 섞어 쓰고, 종합소득세 신고철마다 명세서를 열어 경비를 수동으로 골라내는 사람.

명시적으로 타겟이 아닌 사용자:
- 일반 개인 소비자 (가계부 용도) — 뱅크샐러드·토스가 마이데이터로 무료 제공 중인 영역
- 법인 재무 담당 — 다중 사용자 권한과 보안 실사가 필요해 MVP 범위 밖

## 핵심 기능
1. **CSV 업로드와 자동 파싱** — 카드사별 포맷 차이를 AI 컬럼 매핑으로 흡수. 매핑은 카드사 지문별로 저장해 재사용하므로 두 번째부터는 AI 호출 없이 파싱.
2. **거래별 경비 분류** — 각 거래를 `사업경비 / 개인지출 / 확인필요`로 분류하고 사업경비는 계정과목까지 매핑. 확신도를 함께 산출해 낮은 건은 "확인 필요" 섹션 상단에 노출. 결과는 사용자가 수정 가능한 표.
3. **사용자 규칙 학습** — 사용자가 수정한 분류를 규칙으로 저장하고, 다음 분석 때 AI 호출 전에 선적용한다. 재방문 사용자일수록 정확도가 오르고 원가가 내려간다.
4. **대화형 Q&A (유료)** — "지난 분기 접대비 얼마 썼어?" 같은 자연어 질의. 거래내역을 프롬프트 캐시에 두고 질의만 추가한다.
5. **구독 결제** — Polar 기반. 무료 월 1회 분석 / 유료 월 10회 분석 + Q&A 100건.

## MVP 제외 사항
- 세무 조언·절세 코칭 (틀렸을 때 사용자가 가산세를 문다. 법적 회색지대)
- 마이데이터/오픈뱅킹 자동 연동 (금융위 허가 사항. 장기 해자이나 현 단계 불가)
- 카카오 로그인 (구글 먼저, 검수 리드타임 있음)
- 법인·다중 사용자 워크스페이스
- 영수증 이미지 OCR
- 세무 신고 파일 내보내기 (홈택스 연동 등)

## 디자인
- 라이트 모드 기준. 금융 데이터라 가독성 우선
- 무채색 기반 + 포인트 컬러 1가지. 분류 상태(사업/개인/확인필요)에만 색을 쓴다
- 표 중심의 고밀도 레이아웃. 차트는 보조 역할이며 주인공이 아니다
- 대시보드 상세 화면 구성은 구현하며 확정한다 (의도적 미결정)
