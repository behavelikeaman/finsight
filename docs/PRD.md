# PRD: FinSight

## 목표
카드 명세서·거래 내역 파일을 던지면 AI가 지출 구조와 절감 포인트를 짚어주는 SaaS.

## 사용자

| 페르소나 | 동기 | 성공의 정의 |
|---|---|---|
| **급여생활자** (주) | 카드값이 왜 이렇게 나왔는지 모름 | "아, 배달이 이만큼이었구나"를 60초 안에 |
| **1인 사업자·프리랜서** | 사업 경비와 개인 지출이 섞임 | 카테고리별로 갈라 보고 경비 감 잡기 |

매달 명세서를 받지만 엑셀로 뜯어볼 시간은 없고, 가계부 앱에 매일 입력할 의지도 없는 사람.

## 이 제품을 지배하는 사실

**명세서는 한 달에 한 번 온다.** 재방문 간격이 30일이고 그 사이 사용자는 제품을 잊는다.
첫 방문에서 "다음 달에 또 올 이유"를 심지 못하면 1회용 도구로 끝난다.

요금제를 횟수 제한이 아니라 **시계열 잠금**으로 잡은 이유이자, Free 히스토리를 삭제가 아닌 **잠금**으로 둔 이유다. 잠긴 데이터는 돌아올 이유이자 결제할 이유로 동시에 작동한다.

## 핵심 기능

1. **파일 업로드 + 자동 스키마 매핑** — CSV와 엑셀(.xlsx)을 받는다. 카드사마다 다른 헤더를 휴리스틱으로 추측해 날짜/가맹점/금액에 매핑하고, 사용자가 드롭다운으로 교정한다. 인코딩(EUC-KR/UTF-8), 상단 안내문, 하단 합계 행을 자동 처리한다.
2. **집계 대시보드** — 규칙 기반으로 카테고리를 분류하고 카테고리별·가맹점별·월별 지출을 보여준다. **모든 금액 계산은 코드가 한다.**
3. **AI 인사이트** — 집계된 요약본만 Claude에 전달해 지출 패턴 해석과 절감 제안을 받는다. 계정 연결 후에 생성된다.
4. **계정 + 히스토리** — Google 계정을 연결하면 명세서가 쌓이고 월별로 비교된다.
5. **구독 결제** — Polar로 Pro를 결제하면 전체 히스토리와 심층 리포트가 열린다.

## 요금제

| | Free | Pro |
|---|---|---|
| 업로드 | 무제한 | 무제한 |
| 카테고리 분해 · 상위 가맹점 · 총액 | O | O |
| 기본 AI 요약 (최근 1개월) | O | O |
| 히스토리 열람 | 최근 1개월 | 전체 |
| 월간 비교 · 추세 차트 | X | O |
| 심층 리포트 (구독 누수, 이상 결제, 지출 증가 원인, 절감 제안) | X | O |
| 카드 여러 장 통합 뷰 | X | O |
| CSV 내보내기 · 인쇄 | X | O |

명세서가 월 1회 도착하므로 **횟수 제한은 가치 지표가 아니다.** Free는 단일 명세서 스냅샷을 온전히 체험시키고, 2개월째부터 Pro가 필요해지는 구조다.

**잠금은 삭제가 아니다.** 1개월을 넘은 데이터도 보존되며 서버가 열람만 막는다. 결제 즉시 과거가 복원된다.

## 사용자 흐름

```
랜딩 ─┬─ [로그인] ─────────────────────────▶ 대시보드 (재방문자)
      │
      └─ 파일 드롭 → 컬럼 매핑 확인 → 집계 → 프리뷰
                                              │
                          "현재 결과를 저장하려면 Google 계정을 연결하세요"
                                              ▼
                                   Google 계정 연결 (결과 유지)
                                              ▼
                                    대시보드 · AI 인사이트 생성
                                              ▼
                              (2번째 명세서) 잠긴 비교 차트 → Pro 결제
```

로그인 없이 업로드·집계까지 진행하고, 결과를 저장하는 시점에 계정 연결을 요구한다. 사용자가 이미 자기 파일을 투자한 상태라 전환 저항이 가장 낮다.

**프리뷰 문구는 정직해야 한다.** 익명 단계에서는 AI 인사이트를 생성하지 않으므로, 없는 결과를 블러로 위장하지 않고 "로그인하면 AI 분석을 생성합니다"로 표기한다.

## 정책

- **중복 업로드** — 같은 파일을 다시 올리면 감지해서 저장하지 않고 "취소 / 기존 결과 보기"를 묻는다. 기존 결과가 잠긴 기간이면 "해당 기간은 Pro에서 열람할 수 있습니다"로 안내한다.
- **데이터 삭제** — 내 데이터 전체를 삭제할 수 있다. 단 MVP에서는 앱 데이터 삭제 + 로그아웃까지이고 계정 자체는 남으므로, **"계정 삭제"가 아니라 "내 데이터 전체 삭제"로 표기한다.**
- **업로드 상한** — 10,000행. 초과 시 명확히 안내한다.
- **카드번호는 저장하지 않는다.** 원본 파일도 서버로 전송되지 않는다.

## MVP 제외 사항

- 은행/카드사 API 직접 연동 (오픈뱅킹, 스크래핑) — 파일 업로드만
- PDF 명세서 파싱
- 이메일 리마인더·리포트 발송 ← **재방문이 핵심 가설이라 다음 phase 1순위**
- 팀/조직 계정, 멤버 초대, 권한 관리
- 예산 설정, 알림
- 모바일 앱, PWA 오프라인 지원
- 다국어 (한국어만)
- 거래 내역 수동 편집
- 사용자별 커스텀 카테고리 규칙
- 기존 Google 계정과의 병합, 계정 자체 삭제

## 가설과 지표

| # | 가설 | 관측 지표 |
|---|---|---|
| H1 | 로그인 전에 자기 명세서를 던진다 | 랜딩 → 업로드 시작률 |
| H2 | 매핑 자동 추측 정확도가 첫 이탈을 좌우한다 | 매핑 → 분석 실행률, 수동 교정 비율 |
| H3 | 프리뷰가 계정 연결을 만든다 | 프리뷰 → 연결 완료율 |
| H4 | Pro 전환은 2번째 명세서에서 일어난다 | 재방문 업로드 → 결제율 |
| H5 | **30일 공백을 넘어 돌아온다** ← 가장 약한 고리 | 30일 재방문율 |

## 디자인

- **라이트모드 고정.** 다크모드 미지원 — 테마 분기가 없어 컴포넌트·차트 색 검증 비용이 절반
- 깨끗한 금융형: 흰 배경 + 뉴트럴 그레이 텍스트 + 톤다운된 블루를 주 포인트, 그린/레드는 증감 표시에만
- 은행·회계 SaaS의 신뢰감 문법. 그라디언트·글래스모피즘·과한 애니메이션 금지
- 숫자는 tabular-nums로 정렬. 금액은 천 단위 구분자 + 원화 표기
- PDF 대신 인쇄용 CSS로 대응한다 (라이트모드 고정이라 인쇄 결과가 깨끗하다)
